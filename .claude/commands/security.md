# Security Review

Perform a security-focused review of the requested change.

Check applicable:
- authentication
- authorization / IDOR
- input validation
- injection
- XSS / CSRF
- SSRF
- path traversal
- secrets
- cryptography
- dependency/supply-chain risk
- insecure defaults
- logging/data exposure
- rate limiting
- privilege boundaries
- cloud/IaC permissions
- AI/agent tool abuse and prompt injection

If the `security-audit` skill is installed, use it for a deeper audit when appropriate.
