# Update Documentation

Review the current git diff and update only the documentation that has become stale.

Required:
1. Inspect changed files.
2. Update relevant docs.
3. Add `docs/updates/YYYY-MM-DD-<short-name>.md` for meaningful changes.
4. Update `docs/changelog/CHANGELOG.md`.
5. Add/update an ADR when a durable architectural decision changed.
6. Do not invent facts.
7. Do not duplicate documentation unnecessarily.
